

# 🔹 STEP 2 — JavaScript (CRITICAL for Frontend Interviews)

👉 This section is often **harder than React** and filters many candidates.

---

## 📌 Core JavaScript Concepts

1. What is the difference between:

   * `var`, `let`, `const`
2. What is **hoisting**?
3. What is the **scope chain**?
4. What is a **closure**? (VERY IMPORTANT)
5. What is the difference between:

   * `==` vs `===`

---

## 📌 Functions & Execution

6. What is the difference between:

   * Arrow function vs normal function
7. What is `this` in JavaScript?
8. What are **call**, **apply**, **bind**?

---

## 📌 Async JavaScript (🔥 VERY HIGH PRIORITY)

9. What is the **event loop**?
10. Difference between:

* Callback
* Promise
* Async/Await

11. What are **microtasks vs macrotasks**?
12. What happens in:

```js
console.log("1");

setTimeout(() => console.log("2"), 0);

Promise.resolve().then(() => console.log("3"));

console.log("4");
```

---

## 📌 Arrays & Objects

13. Difference between:

* `map`, `filter`, `reduce`

14. How to clone an object?

* shallow vs deep copy

15. What is immutability and why is it important in React?

## 📌 Memory & Performance

16. What is a memory leak?
17. What is garbage collection?
18. How can closures cause memory issues?
