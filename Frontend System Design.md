# 🎯 What interviewers expect here

They don’t want perfect answers—they want:

* Clear thinking
* Trade-offs (pros/cons)
* Real-world decisions

---

# ⚡ Example (very strong answer style)

👉 Q: *How do you structure a large app?*

**Good answer:**

* Use feature-based structure
* Separate API layer
* Use custom hooks for logic
* Keep components small and reusable
* Centralize state only when necessary
